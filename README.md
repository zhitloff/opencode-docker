# Opencode in docker

Запуск ИИ-агента opencode в docker контейнере с полной изоляцией от внешней сети и окружения хоста.

Подготовка:
1. В [docker-compose.yml](docker-compose.yml) в раздел volumes добавить абсолютный путь до каталога с кодом
2. Запускаем LM Studio или Olama. В их настройках есть запуск web-сервиса для запросов к моделям, как правило адрес будет http://127.0.0.1:1234
3. Запустить docker контейнер. Команды запуска смотри в [opencode.md](opencode.md)

## Подключение облачных провайдеров LLM

В ветке *use-llm-cloud* добавлен вариант обращения opencode к облачным LLM через провайдеры

в корне проекта необходимо создать файл с переменными окружения .env и добавить в него переменную с API-key (анпример ODIROUTER_API_KEY=)
